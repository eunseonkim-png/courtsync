처음 한 번 연결 설정

앱과 Google 계정을 연결하는 공개 ID가 필요합니다. 아래 설정은 한 번만 하면 됩니다.

  1. Google Cloud에서 CourtSync 프로젝트를 만들고 Google Calendar API를 사용 설정합니다.
  2. Google Auth Platform에서 앱 이름과 연락처를 설정하고, 잠재고객을 외부·테스트로 선택해 본인 Gmail을 테스트 사용자로 추가합니다.
  3. 클라이언트 → 웹 애플리케이션을 만들고, 승인된 JavaScript 원본에 https://eunseonkim-png.github.io를 등록합니다.
  4. 발급된 클라이언트 ID를 아래에 붙여넣고 저장합니다. 클라이언트 보안 비밀번호는 사용하지 않습니다.

ID만 이 기기에 저장합니다. Google 로그인 토큰은 저장하지 않으며 앱을 새로고침하면 다시 연결해야 합니다.

등록할 예약을 체크하고 Google 자동 등록을 누르세요. 연결한 계정의 기본 캘린더에 추가합니다.

기존 CourtSync 일정은 날짜·시간·제목을 확인해 중복 추가를 피합니다. 이전에 수동으로 등록했다면 ‘전체 선택’으로 다시 확인할 수 있습니다.

파일 내보내기는 캘린더 등록과 별도입니다. Google 캘린더의 파일 가져오기는 컴퓨터에서 지원합니다.

캘린더에서 내보낸 일정을 모두 추가했나요?

사용 방법 · 등록 표시 안내
  1. 강동구 예약목록 표 전체를 붙여넣고 예약을 추출합니다.
  2. 처음 한 번 Google 연결 설정을 마치고 Google 캘린더를 연결합니다.
  3. 등록할 예약을 선택하고 ‘Google에 자동 등록’을 누릅니다. 새 일정은 저장하고 같은 일정이 있으면 기존 등록을 확인합니다.

한꺼번에 옮길 때는 원하는 예약을 선택해 .ics 파일로 내보내세요. Google 캘린더에서는 컴퓨터의 설정 → 가져오기 및 내보내기에서 파일을 가져옵니다.

‘Google 등록완료’는 Google API로 저장하거나 기존 일정을 확인한 기록입니다. ‘등록완료 · 직접 확인’은 개별 추가 또는 파일 가져오기 후 사용자가 확인한 표시입니다.

일부 일정이 실패하면 성공한 예약만 등록완료로 표시하고, 남은 예약은 선택된 상태로 유지합니다. 인터넷 연결이나 Google 권한을 확인한 뒤 다시 시도하세요.

앱 새로고침은 저장한 예약목록과 등록 이력을 유지합니다. 붙여넣기 원문과 Google 로그인 토큰은 저장하지 않으므로 새로고침 후 다시 입력하거나 연결해야 합니다.

예약목록을 새로 추출하면 이번에 붙여넣은 목록으로 바뀝니다. 등록 이력은 유지됩니다. 예약 취소나 시간 변경은 캘린더에서도 직접 반영해 주세요.
